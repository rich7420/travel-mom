# 旅行社小幫手使用指南

文件狀態：操作說明草稿。更新日期：2026 年 10 月 3 日。

您可以在網頁接單、保存查價需求、錄入實際方案、選案與整理回覆。未啟用自動查詢也能使用，不必操作後台服務。

## 五分鐘開始第一個案件

1. 從主畫面的「新客人」建立案件，填目的地、日期、人數與預算。
2. 開啟案件，補齊旅客與偏好；用旅行社平常的方式查機票或飯店。
3. 按「錄入供應商方案」，保存核對過的實際價格與條件，再到「比較與選方案」選用。
4. 按「回覆這位客人」，修改草稿後複製，貼到您原本的訊息工具，由您核對並送出。

工具保存案件、查價需求、人工方案與選取。尚未送出的回覆文字請先複製保留；一般訊息草稿不會自動存成正式報價；正式價格請到案件的「報價版本」建立。

## 開啟與第一次設定

使用管理員提供的旅行社小幫手網址。本機試用入口只適用這台電腦；手機或另一台電腦需使用管理員另外提供的入口。

從主畫面右上角或「設定」按「使用指南（另開分頁）」可閱讀本指南；處理案件時，視窗右上角也有對應說明。閱讀完切回原本的操作分頁，未送出的表單仍留在原處。指南中的「開啟工作台」會開啟另一個工作台頁面，不會恢復原分頁尚未儲存的文字。

若航空／飯店清單或偏好設定暫時讀取失敗，可按個別「重試」，仍可開啟案件與人工錄入方案。

第一次選擇平常出發的機場與字體大小，按「開始使用」。之後可到「設定」修改機場、常用航空與字體。本機若要求「連線密碼」，請輸入管理員提供的密碼。之後若採用線上登入，使用管理員允許的帳號登入，設定頁會顯示登入帳號與「登出」；登入到期時，提示不會蓋掉原本案件畫面與文字，請按「開啟登入頁（另開分頁）」完成登入，再切回原分頁按「我已登入，繼續處理」。原表單會保留，您可以再次儲存。案件處理視窗中未儲存的表單與回覆草稿在關閉視窗、返回或換畫面時會提醒；按「取消」可保留原畫面繼續編輯，確定離開則捨棄這次未儲存內容。儲存中請等待結果，不能同時離開。重新整理或關閉分頁也會要求瀏覽器提醒，但文字沒有另外備份，仍請先儲存或複製。重新登入使用自己的帳號，不需要共用管理密碼。

右上角「網頁工作模式」表示可使用本次完成的網頁功能；目前不會自動查到即時票價或房價。「自動查詢已設定」表示管理員已設定選配服務，實際是否成功仍需看查詢結果。

畫面中的「示範」案件與價格是練習資料，不能用於真實客人報價。請先使用稱呼與一般需求，不要把護照、完整證件、信用卡或驗證碼貼入一般欄位。

## 建立與接續案件

1. 按導覽列「新客人」，輸入客人稱呼。桌機導覽在左側，手機在下方。
2. 填目的地，例如「東京」，或選「還沒決定」。
3. 填出發日，例如 `2026-10-18`，或選日期未定。
4. 填回程日，例如 `2026-10-22`，或選回程未定。回程不可早於出發。
5. 填實際人數，例如 `2大1小`；有嬰兒可填 `2大1小1嬰兒`。團體請填實際人數，不會自動假設 10 人。
6. 填全團總預算，例如 `10萬內`，或先不設預算。

按「上一步」可更正；按「先存起來」後，在同一瀏覽器按「新客人」可接著未完成的問題。已建立完成後，再按「新客人」會開始下一位，不會覆蓋前一個案件。

完成畫面可直接選「查機票」、「查飯店」、「錄入已查到的方案」、「回覆客人」或「打開案件」。

## 修改需求與旅客

到「案件」，以稱呼或目的地搜尋，按「繼續處理」，再按「修改需求與旅客資料」。可以修改日期、人數、預算、偏好與案件進度。

有小孩時，補上每位小孩年齡，例如 `5, 8`。年齡數量必須與小孩人數一致；未知時可暫存空白，但錄入人工方案前需先確認。嬰兒另外填人數；飯店查詢還需要嬰兒年齡，填在小孩年齡後方。

修改目的地、日期或旅客後，原方案會要求重新查價，不能直接沿用舊價格。若表單提示資料錯誤，原案件不會被錯誤資料覆蓋。

日期、目的地或旅客真的變更時，訂購／已確認案件會回到查價與報價中；即使把日期改回原值，也不會自動恢復已確認，仍需依流程重新核對。

## 保存機票與飯店查價需求

從案件按「查機票」或「查飯店」，日期與旅客會帶入。從首頁進入時，先選案件，表單也會帶入該客人的需求。

機票需確認三碼機場代碼，例如桃園 `TPE`、關西 `KIX`。東京可能是成田 `NRT` 或羽田 `HND`，系統會列出選項，由您確認。填好航空偏好後按「保存查價條件」。單程可留白回程。

飯店需填飯店名稱、分館官網、房數及早餐／取消偏好。小孩與嬰兒都要填年齡，例如一位 7 歲小孩、一位 1 歲嬰兒填 `7, 1`。不能只填成人而漏掉其他旅客。獨立飯店的官網需先由管理員確認；若目前只拿到供應商報價，可直接使用人工錄入，不必先建立官網查詢。

已綁定案件的查價日期、人數與需求需一致；客人改需求時，先修改案件，再重新查價。

**保存查價條件不等於已取得價格。** 未啟用自動查詢時，請照旅行社原本方式查價，再把實際方案錄入工具。

## 錄入實際查到的方案

從案件按「錄入供應商方案」，或在查價表單按「錄入人工查價」。

1. 核對客人、日期與完整旅客人數。
2. 選「機票」或「飯店」，填供應商與方案名稱。
3. 填 **對客參考總價** 與幣別：機票是案件所有旅客的此項總價；飯店是所有房間、完整住宿期間的此項總價。不要填每人價、每晚價或內部成本來代替。
4. 填方案內容，例如航班時段、行李，或房數、床型、早餐。
5. 填退改、取消、額外費用與待確認項目；未知就寫「待確認」。
6. 填內部來源紀錄、實際查詢時間，以及供應商有效期限。期限未知可留白。
7. 如有內部來源網址，可填入；這個網址只留在案件，不會出現在客戶草稿。內部窗口或 Email 紀錄會留在案件，不會放進草稿。
8. 勾選已確認符合案件與實際總價，按「保存這個方案」。

保存只新增候選方案，不會訂購、付款或保留機位／房間。客人變更需求或供應商更新價格時，錄入一個新方案並重新選取，保留原本的查價紀錄。

方案未填供應商有效期限時，預設查詢後 24 小時需要重新確認；有填有效期限時以該期限為準。這個 24 小時是參考方案的預設重新確認時間，不保證供應商仍有相同價格或庫存，也不是開票或取消期限。管理工作台的官網付款前檢查另有預設 20 分鐘的新鮮度要求，並不代表媽媽介面已完成訂購。訂購前仍需重新查價。內部供應商名稱、來源紀錄、來源網址與解析警告不會自動放入客戶草稿；方案名稱、內容和條件請填客戶可見文字。

## 比較與選方案

在案件按「比較與選方案」，可查看人工錄入方案；若自動查詢已啟用且本次成功，也可能看到通過驗證的官網候選結果。沒有結果時，先查價或錄入方案。每張卡片顯示價格、幣別、內容、條件、來源與查詢時間。

按「選用這個參考方案」，每個案件可選一個機票與一個飯店；選另一個同類方案會取代原選取。按「取消選取」可清除該類選案。

| 卡片狀況 | 如何處理 |
| --- | --- |
| 已選取 | 可用於整理參考方案草稿，仍未訂購 |
| 案件需求已變更 | 重新查價並錄入符合新需求的方案 |
| 供應商報價已過期 | 重新向供應商確認價格與條件 |
| 官網價格需要重新查詢 | 重查官網，或把人工確認的新價格另行錄入 |
| 示範資料 | 可看流程，不能選用為客戶報價 |
| 方案內容已更新 | 核對更新內容，再重新選取 |

不同幣別分開看，工具不會把台幣與日圓直接相加。缺少項目也不代表費用是零。

## 整理與修改客戶回覆

1. 從案件或選案畫面按「回覆客人」。
2. 貼客人的一般訊息，按「先幫我寫草稿」。
3. 有可用選案時，草稿會整理方案明細、對客參考總價、公開來源與查詢時間。同幣別的機票與飯店可合計，不同幣別不換算。
4. 沒有選案、方案過期或需求已變更時，草稿只確認需求，不會把舊價格當成有效方案。
5. 直接在「回覆草稿」文字框修改。
6. 按「複製目前草稿」，貼到 LINE 或您原本的訊息工具；核對後由您送出。若瀏覽器不允許複製，按提示手動複製選取的文字。

未啟用 AI 時，使用的是固定格式草稿，適合確認需求與整理已選方案，不會自由理解所有客人問題。它不會自行回答簽證資格、承諾機位／房況，或代您傳訊息。草稿中的未確認項目仍需人工查證。

四種回饋可記錄「可以直接用」、「我有修改」、「以後都這樣」、「不要這樣」。目前先累積改進紀錄，不會按一下就立即改變下次回覆。

## 查價紀錄與今天的工作

「今天」的工作總覽以深藍色區塊顯示案件數與建議先處理的工作，下方依序列出優先案件；其他最近案件在旁邊或下方。首頁的「接單 → 查價 → 選方案 → 回客人」是一般工作流程說明，不代表案件已完成或訂購成功。「查價紀錄」預設收合，按標題可展開。查價完成後紀錄仍保留，可打開案件查看方案。

若之後啟用自動查詢，使用方式仍是這個網頁：建立查詢、查看進度與結果、選取方案。登入、驗證、付款或最終訂購由本人操作；後台服務不需要媽媽自行使用。

「今天」另外列出所有逾期與今天到期的未完成待辦；導覽列「待辦」可查看全部未完成、已完成或已取消的待辦。工作期限放在常用工作上方；案件優先順序也會考慮逾期與今日待辦。案件與首頁的「下一步」會依報價、訂購及行前交付紀錄更新。長時間官網工作遇到服務重啟也不保證自動續跑，請管理員協助恢復。

## 正式報價與客人採用版本

1. 開啟案件的「報價版本」，按「建立報價新版」。先選好仍有效、符合需求的機票／飯店方案。
2. 填報價名稱、有效期限、包含與不含項目，尤其退改與付款條件。有效期限不能超過所選供應商價格的期限。
3. 各幣別可加服務費或折扣；內部成本可留白，成本不完整時毛利顯示「待核對」。金額不跨幣別換算。
4. 保存後按「開啟對客文件／列印」。可以列印成 PDF，或在文件頁「複製對客內容」，再由您貼到 LINE／Email 送出。若新分頁被阻擋，允許此網站開啟分頁。
5. 實際送出後回案件按「記錄已人工送出」，填核對依據、實際完成時間並勾選。
6. 收到明確決定後按「記錄客人採用」或「記錄客人未採用」。只有未過期、需求未變的已送出版本能採用。

每版保留建立時的需求、價格與條件，對客文件不含內部成本、供應商窗口或處理依據。修改請建立新版；舊版保留，採用新版時其他未定或已採用版本會被取代。已有採用版本時，需核對異動影響並寫原因；原收付款保留，舊版訂購確認可按「重新核對／沿用至本版」，核對供應商後填理由與新版對客內容；訂購核對後仍需到「行前交付」重新核對對應文件，再產生新版摘要。過期或已取代的文件會標示為歷史參考，不要再當有效報價送出。

## 期限待辦與追蹤

從案件的「期限待辦」新增項目，可先選常用待辦（回覆、訂金、尾款、開票、取消、補件或行前交付），再填負責人、實際期限、來源與備註。常用待辦只帶入名稱與種類，期限不會由系統猜測。可關聯報價、訂購或文件。例如供應商要求明天下午開票，就選「開票期限」，填通知來源；它與報價有效時間是不同的期限。

導覽「待辦」顯示全部待辦，不只首頁的優先案件。首頁列出逾期與今天到期的未完成項目。清單以台北時間顯示；輸入表單使用裝置時區，送出後會換算。請確認裝置時間設定。

完成、取消或改期時按「更新期限／完成待辦」，填這次原因或完成依據。記錄保留；同時被另一人改過會請您重開核對，不會直接覆蓋。系統目前沒有自動推播或替您聯絡客人，請每天查看清單。

## 訂購確認與錯誤修正

1. 先在「報價版本」記錄客人採用哪一版。
2. 使用旅行社／供應商原系統完成訂購；查價結果不是訂購證據。
3. 到「訂購確認」按「新增訂購確認」，填種類、對客名稱與內容、內部供應商、正式確認號。
4. 核對供應商正式通知、日期、旅客與內容，填依據和完成時間，勾選後儲存。

報價中機票與飯店各項都已有符合本版的確認時，案件進度才會更新為已確認。這只表示已人工登錄；不是本站執行了交易。確認號與對客內容會放入行前摘要，內部窗口與依據不會。

填錯時「作廢錯誤紀錄」並說明原因，再新增正確紀錄。作廢本站紀錄不會取消供應商訂單；真正取消或改期仍要另行聯絡供應商。採用新版報價後，舊確認仍保留並標示需重新核對。確認號仍有效時，按「重新核對／沿用至本版」，核對供應商並填新版內容與依據，不必作廢仍有效的訂單；完成後請重新核對相應電子機票／住宿憑證，再產生新版行前摘要。若確認號也出現在其他案件，工具會提示，請核對是否同一團體或誤填。

## 收付款與分幣別對帳

從案件「收付款」新增**已實際發生**的客人收款、退還客人、付供應商或供應商退款。填金額、三碼幣別、實際時間及憑據，勾選已核對；可關聯訂購。預定訂金或尾款請放期限待辦，不要記成已收到。

每個幣別分別顯示報價、客人淨收款、尚欠、供應商淨付款與收付差額。尚欠負數代表溢收。與報價不匹配的幣別、未知成本會顯示待核對，不會假設零或自動換匯。收付差額是現金紀錄，不等於毛利。

退款不得超過同案件、同幣別的原收／付款。填錯可作廢並重建；如果作廢會令退款超出原額，先核對與修正相關退款記錄。這個頁面不會轉帳、收款，也不取代公司正式會計或收據流程。

## 文件缺件與行前交付

簽證、入境、海關、保險與契約／退改規定，請在回客人、準備報價與行前交付時，到主管機關及實際供應商官網重新確認。核對旅客條件、產品與適用日期，在案件備註或文件核對依據記下官方網址、查核時間、版本／生效日期及待確認項目；不要貼完整證件號碼。網頁目前不會自動查核法規或判定簽證資格，文件標記「已備妥」仍需要您人工確認。

1. 到「行前交付」新增文件清單。每筆有效機票訂購必備自己的電子機票、每筆飯店訂購必備自己的住宿憑證，備妥時需關聯對應的訂購紀錄；其他行程、簽證檢查、保險等可自行加入。
2. 在「核對文件／補件」填對客說明或 HTTPS 文件連結，再核對日期與旅客、填依據並標記「文件已備妥」。系統不會自動下載或驗證連結。若原訂購紀錄已作廢，可以在此修正關聯訂購；誤加的必備項目可取消必備標示。這兩種修正都要填原因與核對依據，保留歷史。
3. 按「產生行前摘要新版」。缺訂購確認或必備文件時，會列出缺件並產生草稿，不能複製、列印或記錄交付。
4. 補齊後重新產生摘要，按「開啟對客文件／列印」核對文字與連結；原始電子機票、住宿憑證等附件仍須您另外提供。
5. 實際交付完整資料後，按「記錄已人工交付」，填管道、依據與實際時間並勾選。

改期、變更目的地或旅客，以及訂購重新核對／換採用報價後，請先重新核對對應文件，再產生新版摘要；訂購確認號相同，也不代表原憑證仍適用。系統會標示需要重新核對的文件；升級前已標記備妥、但沒有版本核對紀錄的文件也需要您確認一次。沒有關聯訂購的行程／保險等文件，單純費用改版不會要求重核，但旅遊需求改變仍需重核。舊摘要會標示失效，不能繼續輸出或記錄交付；已交付的舊版也不能直接重新輸出給客人。已交付的紀錄與版本仍保留。文件連結請使用適合給該客人的受控連結，不要包含帳密或內部資料。

## 結案與重新開案

打開案件後，在五個「案件工作」按鈕下方按「結案與重新開案」。這是整理本站業務進度；不會取消供應商訂單、轉帳、退款或通知客人。

- **完成業務結案**：先完成所有待辦、客人採用報價、有效訂購、必備文件與目前行前摘要的人工交付；各幣別客人款項須結清。結案時填原因、核對依據、實際時間，並確認供應商結算與後續服務已人工處理。系統無法由收付款差額判定供應商是否已結清。
- **未成交結案**：須沒有未完成待辦、有效訂購或未沖回的收付款。若客人曾採用報價，必須明確勾選撤回採用；原採用歷史保留，重新開案也不會恢復採用。
- **重新開案**：填原因、核對依據、時間並確認。系統依目前有效報價及訂購推算「確認需求中／查價與報價中／準備訂購／已人工確認訂購」，不會猜測旅途中。需要新版報價時仍須重新查價、送出並記錄客人決定。

畫面會列出尚未符合的條件。實際執行中的查價／瀏覽任務不能結案；尚未啟動的計畫可保留。卡住的執行需管理員先停止工作程序，再記錄中止。結案後保留歷史與可用的對客文件，修改或新增紀錄前須先重新開案。若畫面提示資料已變更，返回重開此區並重新核對；不要只重複按儲存。實際完成交付與對帳不代表旅行已結束。


## 常見問題與卡住時怎麼做

### 已保存查價條件，為什麼沒有價格？

保存的是需求，不是價格。若畫面顯示「網頁工作模式」，請照原本方式查價，然後從案件「錄入供應商方案」。只看到「已完成」也要核對是否真的有可用方案。

### 方案不能選，要怎麼處理？

看卡片原因：需求變更就重查符合新需求的方案；報價過期就向供應商確認後錄入新價格；示範資料只能練習。不要為了繼續操作而把舊方案改成已確認。

### 草稿不能複製，或尚未送出就離開？

如果自動複製失敗，按提示手動複製選取文字。離開、重新整理或重新登入前，先保留尚未送出的草稿；案件與選案會保存，回覆文字不保證重新載入後還在。看指南請另開分頁，不必關閉原表單。

### 連線失敗，或輸入內容被退回？

若顯示「已保存」，表單會改成唯讀；請按「重新載入已保存紀錄」查看結果，不要再送出一次。其他連線失敗先確認網路，再用畫面上的重試按鈕；仍需編輯的內容請留在原分頁，不要直接重新整理瀏覽器。表單提示日期、人數或年齡有誤時，核對欄位後再保存；不合法修改不會覆蓋原案件。持續失敗時，把畫面上的訊息告訴管理員，不要提供密碼或驗證碼。

## 還需要使用旅行社原本流程的工作

目前可以記錄機票／飯店從售前到成交後的人工工作，但供應商交易與原始文件交付仍需旅行社原本流程。以下尚未完整提供：

- 真正訂位、開票、取消供應商訂單、銀行轉帳與退款執行。
- 原始附件上傳、電子機票／住宿憑證自動合併、護照 OCR 與完整旅客名冊。
- 自動催款／催件訊息與手機推播；須由您查看期限清單並自行聯絡。
- 多日行程、團體配額、簽證資格、保險、接送與其他產品的專門流程。
- 改退費規則計算、旅中異常、完整 CRM、多人交接與按客戶分權限。

若之後啟用自動查詢，它仍屬選配功能，真實官網能否穩定查到結果尚未驗證；需以每次實際結果為準。管理工作台另有官網重新驗價與付款前檢查，這些是工程／管理功能，尚未接成媽媽介面的完整訂購流程。

不要只因為案件狀態改成「已確認」就認為訂位或訂房已完成；先核對供應商正式確認。方案的有效期限也不是開票或免費取消期限。

「問助理」目前主要協助選工作，不會自動定位所有口語提到的客人或完成整件事；請選對案件後再操作。「做行程／查簽證」提示不等於已有完整功能。

選案、草稿或查詢完成都不代表訂單成立，以供應商正式確認為準。本草稿已經桌面與手機寬度操作核對，仍需媽媽實際試用後調整用語與順序。
