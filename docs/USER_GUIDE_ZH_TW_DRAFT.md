# 旅行社小幫手使用指南

文件狀態：操作說明草稿。更新日期：2026 年 10 月 3 日。

您可以在網頁接單、保存查價需求、錄入實際方案、選案與整理回覆。未啟用自動查詢也能使用，不必操作後台服務。

## 五分鐘開始第一個案件

1. 從主畫面的「新客人」建立案件，填目的地、日期、人數與預算。
2. 開啟案件，補齊旅客與偏好；用旅行社平常的方式查機票或飯店。
3. 按「錄入供應商方案」，保存核對過的實際價格與條件，再到「比較與選方案」選用。
4. 按「回覆這位客人」，修改草稿後複製，貼到您原本的訊息工具，由您核對並送出。

工具保存案件、查價需求、人工方案與選取。尚未送出的回覆文字請先複製保留；不會自動存成正式報價單。

## 開啟與第一次設定

使用管理員提供的旅行社小幫手網址。本機試用入口只適用這台電腦；手機或另一台電腦需使用管理員另外提供的入口。

從主畫面右上角或「設定」按「使用指南（另開分頁）」可閱讀本指南；處理案件時，視窗右上角也有對應說明。閱讀完切回原本的操作分頁，未送出的表單仍留在原處。指南中的「開啟工作台」會開啟另一個工作台頁面，不會恢復原分頁尚未儲存的文字。

第一次選擇平常出發的機場與字體大小，按「開始使用」。之後可到「設定」修改機場、常用航空與字體。本機若要求「連線密碼」，請輸入管理員提供的密碼。之後若採用線上登入，使用管理員允許的帳號登入，設定頁會顯示登入帳號與「登出」；登入到期時，提示不會蓋掉原本案件畫面與文字，但按「重新登入」會重新載入頁面，尚未儲存的文字可能需要重填。請在工作過程中先複製重要草稿，不要等到登入到期才保留。重新登入使用自己的帳號，不需要共用管理密碼。

右上角「網頁工作模式」表示可使用本次完成的網頁功能；目前不會自動查到即時票價或房價。「自動查詢已設定」表示管理員已設定選配服務，實際是否成功仍需看查詢結果。

畫面中的「示範」案件與價格是練習資料，不能用於真實客人報價。請先使用稱呼與一般需求，不要把護照、完整證件、信用卡或驗證碼貼入一般欄位。

## 建立與接續案件

1. 按導覽列「新客人」，輸入客人稱呼。桌機導覽在左側，手機在下方。
2. 填目的地，例如「東京」，或選「還沒決定」。
3. 填出發日，例如 `2026-10-18`，或選日期未定。
4. 填回程日，例如 `2026-10-22`，或選回程未定。回程不可早於出發。
5. 填實際人數，例如 `2大1小`；有嬰兒可填 `2大1小1嬰兒`。團體請填實際人數，不會自動假設 10 人。
6. 填全團總預算，例如 `10萬內`，或先不設預算。

按「上一步」可更正；按「先存起來」後，在同一瀏覽器按「新客人」可接著未完成的問題。已建立完成後，再按「新客人」會開始下一位，不會覆蓋前一個案件。

完成畫面可直接選「查機票」、「查飯店」、「錄入已查到的方案」、「回覆客人」或「打開案件」。

## 修改需求與旅客

到「案件」，以稱呼或目的地搜尋，按「繼續處理」，再按「修改需求與旅客資料」。可以修改日期、人數、預算、偏好與案件進度。

有小孩時，補上每位小孩年齡，例如 `5, 8`。年齡數量必須與小孩人數一致；未知時可暫存空白，但錄入人工方案前需先確認。嬰兒另外填人數；飯店查詢還需要嬰兒年齡，填在小孩年齡後方。

修改目的地、日期或旅客後，原方案會要求重新查價，不能直接沿用舊價格。若表單提示資料錯誤，原案件不會被錯誤資料覆蓋。

## 保存機票與飯店查價需求

從案件按「查機票」或「查飯店」，日期與旅客會帶入。從首頁進入時，先選案件，表單也會帶入該客人的需求。

機票需確認三碼機場代碼，例如桃園 `TPE`、關西 `KIX`。東京可能是成田 `NRT` 或羽田 `HND`，系統會列出選項，由您確認。填好航空偏好後按「保存查價條件」。單程可留白回程。

飯店需填飯店名稱、分館官網、房數及早餐／取消偏好。小孩與嬰兒都要填年齡，例如一位 7 歲小孩、一位 1 歲嬰兒填 `7, 1`。不能只填成人而漏掉其他旅客。獨立飯店的官網需先由管理員確認；若目前只拿到供應商報價，可直接使用人工錄入，不必先建立官網查詢。

已綁定案件的查價日期、人數與需求需一致；客人改需求時，先修改案件，再重新查價。

**保存查價條件不等於已取得價格。** 未啟用自動查詢時，請照旅行社原本方式查價，再把實際方案錄入工具。

## 錄入實際查到的方案

從案件按「錄入供應商方案」，或在查價表單按「錄入人工查價」。

1. 核對客人、日期與完整旅客人數。
2. 選「機票」或「飯店」，填供應商與方案名稱。
3. 填 **對客參考總價** 與幣別：機票是案件所有旅客的此項總價；飯店是所有房間、完整住宿期間的此項總價。不要填每人價、每晚價或內部成本來代替。
4. 填方案內容，例如航班時段、行李，或房數、床型、早餐。
5. 填退改、取消、額外費用與待確認項目；未知就寫「待確認」。
6. 填內部來源紀錄、實際查詢時間，以及供應商有效期限。期限未知可留白。
7. 如有內部來源網址，可填入；這個網址只留在案件，不會出現在客戶草稿。內部窗口或 Email 紀錄會留在案件，不會放進草稿。
8. 勾選已確認符合案件與實際總價，按「保存這個方案」。

保存只新增候選方案，不會訂購、付款或保留機位／房間。客人變更需求或供應商更新價格時，錄入一個新方案並重新選取，保留原本的查價紀錄。

方案未填供應商有效期限時，預設查詢後 24 小時需要重新確認；有填有效期限時以該期限為準。這個 24 小時是參考方案的預設重新確認時間，不保證供應商仍有相同價格或庫存，也不是開票或取消期限。管理工作台的官網付款前檢查另有預設 20 分鐘的新鮮度要求，並不代表媽媽介面已完成訂購。訂購前仍需重新查價。內部供應商名稱、來源紀錄、來源網址與解析警告不會自動放入客戶草稿；方案名稱、內容和條件請填客戶可見文字。

## 比較與選方案

在案件按「比較與選方案」，可查看人工錄入方案；若自動查詢已啟用且本次成功，也可能看到通過驗證的官網候選結果。沒有結果時，先查價或錄入方案。每張卡片顯示價格、幣別、內容、條件、來源與查詢時間。

按「選用這個參考方案」，每個案件可選一個機票與一個飯店；選另一個同類方案會取代原選取。按「取消選取」可清除該類選案。

| 卡片狀況 | 如何處理 |
| --- | --- |
| 已選取 | 可用於整理參考方案草稿，仍未訂購 |
| 案件需求已變更 | 重新查價並錄入符合新需求的方案 |
| 供應商報價已過期 | 重新向供應商確認價格與條件 |
| 官網價格需要重新查詢 | 重查官網，或把人工確認的新價格另行錄入 |
| 示範資料 | 可看流程，不能選用為客戶報價 |
| 方案內容已更新 | 核對更新內容，再重新選取 |

不同幣別分開看，工具不會把台幣與日圓直接相加。缺少項目也不代表費用是零。

## 整理與修改客戶回覆

1. 從案件或選案畫面按「回覆客人」。
2. 貼客人的一般訊息，按「先幫我寫草稿」。
3. 有可用選案時，草稿會整理方案明細、對客參考總價、公開來源與查詢時間。同幣別的機票與飯店可合計，不同幣別不換算。
4. 沒有選案、方案過期或需求已變更時，草稿只確認需求，不會把舊價格當成有效方案。
5. 直接在「回覆草稿」文字框修改。
6. 按「複製目前草稿」，貼到 LINE 或您原本的訊息工具；核對後由您送出。若瀏覽器不允許複製，按提示手動複製選取的文字。

未啟用 AI 時，使用的是固定格式草稿，適合確認需求與整理已選方案，不會自由理解所有客人問題。它不會自行回答簽證資格、承諾機位／房況，或代您傳訊息。草稿中的未確認項目仍需人工查證。

四種回饋可記錄「可以直接用」、「我有修改」、「以後都這樣」、「不要這樣」。目前先累積改進紀錄，不會按一下就立即改變下次回覆。

## 查價紀錄與今天的工作

「今天」的工作總覽以深藍色區塊顯示案件數與建議先處理的工作，下方依序列出優先案件；其他最近案件在旁邊或下方。首頁的「接單 → 查價 → 選方案 → 回客人」是一般工作流程說明，不代表案件已完成或訂購成功。「查價紀錄」預設收合，按標題可展開。查價完成後紀錄仍保留，可打開案件查看方案。

若之後啟用自動查詢，使用方式仍是這個網頁：建立查詢、查看進度與結果、選取方案。登入、驗證、付款或最終訂購由本人操作；後台服務不需要媽媽自行使用。

目前「今天」依出發日與案件狀態排序，還不是完整的付款、開票或取消期限清單。長時間官網工作遇到服務重啟也不保證自動續跑，請管理員協助恢復。

## 常見問題與卡住時怎麼做

### 已保存查價條件，為什麼沒有價格？

保存的是需求，不是價格。若畫面顯示「網頁工作模式」，請照原本方式查價，然後從案件「錄入供應商方案」。只看到「已完成」也要核對是否真的有可用方案。

### 方案不能選，要怎麼處理？

看卡片原因：需求變更就重查符合新需求的方案；報價過期就向供應商確認後錄入新價格；示範資料只能練習。不要為了繼續操作而把舊方案改成已確認。

### 草稿不能複製，或尚未送出就離開？

如果自動複製失敗，按提示手動複製選取文字。離開、重新整理或重新登入前，先保留尚未送出的草稿；案件與選案會保存，回覆文字不保證重新載入後還在。看指南請另開分頁，不必關閉原表單。

### 連線失敗，或輸入內容被退回？

先確認網路並按「重新整理」重試。表單提示日期、人數或年齡有誤時，核對欄位後再保存；不合法修改不會覆蓋原案件。持續失敗時，把畫面上的訊息告訴管理員，不要提供密碼或驗證碼。

## 還需要使用旅行社原本流程的工作

目前主要輔助機票／飯店的售前工作，還不能包辦大部分完整旅行社任務。以下仍需使用原本的紀錄與人工流程：

- 正式報價版本、客人接受哪一版、服務費與成本／毛利。
- 催回覆、訂金與尾款、開票、免費取消等期限與提醒。
- 收付款對帳、正式訂購確認、票號／訂位代號、飯店確認單。
- 旅客文件缺件、電子機票與住宿憑證、行前包與交付確認。
- 多日行程、團體配額、簽證、保險、接送與其他旅遊產品。
- 改期、取消、退款、旅中異常、售後與多人交接。

若之後啟用自動查詢，它仍屬選配功能，真實官網能否穩定查到結果尚未驗證；需以每次實際結果為準。管理工作台另有官網重新驗價與付款前檢查，這些是工程／管理功能，尚未接成媽媽介面的完整訂購流程。

不要只因為案件狀態改成「已確認」就認為訂位或訂房已完成；先核對供應商正式確認。方案的有效期限也不是開票或免費取消期限。

「問助理」目前主要協助選工作，不會自動定位所有口語提到的客人或完成整件事；請選對案件後再操作。「做行程／查簽證」提示不等於已有完整功能。

選案、草稿或查詢完成都不代表訂單成立，以供應商正式確認為準。本草稿已經桌面與手機寬度操作核對，仍需媽媽實際試用後調整用語與順序。
