# POC Scope — v0.7

## Implemented

- TripCase CRUD and guided one-question-at-a-time intake.
- Mobile-first dashboard for future LINE MINI App use.
- LINE/Telegram adapters with verification, allowlists and replay protection.
- Private OpenClaw Gateway adapter with separate conversation/browser agents.
- Persistent FlightSearchRun and HotelSearchRun.
- Eight airline official-site semantic recipes: CI/BR/CX/JX/AE/IT/EK/NH.
- Airline typed search, comparison, revalidation and booking preflight.
- Hotel built-in official-network registry + human-approved independent site grants.
- Hotel typed search, comparison, revalidation and booking preflight.
- BrowserAttempt telemetry and supplier-aware Browser Lab.
- Application-level approval policy; payment/card/CVV/OTP/3DS/CAPTCHA bypass prohibited.
- Optional encrypted local PII vault.
- 19 OpenClaw workspace skills and audited semantic recipes.

## Deliberately not claimed

- Live fare/availability accuracy before Browser Lab validation.
- Automated final flight ticketing or hotel booking.
- Payment/card entry.
- CAPTCHA/OTP/3DS bypass.
- General automatic trust of arbitrary hotel websites.
- Production CRM/accounting/GDS synchronization.
- Authoritative visa/entry decisions without an authoritative provider.
- Production multi-user security/backup/monitoring readiness.
